The 30-second answer
  • Chennai has chapter-based groups in many neighbourhoods plus newer clubs; Kolkata's clubs meet at lakes and parks like Rabindra Sarobar and Eco Park.
  • Several clubs post the start point on Instagram or WhatsApp just before each run.
  • This list is short on purpose: only clubs we could confirm are in.

Chennai and Kolkata both have run clubs that meet near the water, early in the morning, and most welcome new runners. Below are the clubs we could confirm in each city, with what each source says about where and when they meet.

Looking for the full list? See the Run Clubs in Chennai directory (7 clubs, each linked to its source). This post explains how clubs work here; the directory is the page we keep up to date. Each page cites its own sources, so a club can appear in one and not the other.

How run clubs work in these two cities

Chennai Runners works through chapters: its chapters page lists sixteen, each named for an area, from Alwarpet to Velachery, and the site also mentions a free Couch to 5K programme and the Freshworks Chennai Marathon. Kolkata's Calcutta Run Club says it is free, with no membership or registration, and each run is a 5K at your own pace with games and a cafe stop. Both cities also have smaller clubs that post the start point on Instagram or WhatsApp shortly before each run.

Popular places to run

We only name places the clubs themselves use. In Chennai: Besant Nagar and Marina Beach, plus Anna Nagar. In Kolkata: Rabindra Sarovar, Eco Park in New Town, Lake Gardens and Elliot Park. Entry rules and timings were not on the pages we read, so check locally, and see running in Indian heat and monsoon for planning around humidity and rain.

What to bring and what to ask before joining

  • Bring: water, shoes you have already run in, your phone and some cash or UPI for the cafe.
  • Ask: Where exactly is the start today? Is there a beginner pace? Is it free? Do I need to join a WhatsApp group first?
  • Health: if you are unsure about your fitness, talk to a doctor first. A 5K plan helps first-timers.

Quick questions

Are there run clubs near the beach in Chennai?

Yes. Chennai Runners' chapters list Besant Nagar and Marina Beach among their start locations, and a directory lists VAMOS Run Club and Bat Club around the beach loop and Anna Nagar.

Is Calcutta Run Club free?

Its own site calls it a free, community-driven group, with no membership or registration and a 5K at your own pace.

Which day does Calcutta Run Club meet?

Its site says Sundays at 6 AM, while a directory lists Saturday 6:30 AM. Check its Instagram before you go.
