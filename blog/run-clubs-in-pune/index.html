The 30-second answer
  • Pune clubs are mostly Sunday-morning groups, and several send the exact start point only to people who register.
  • Alpha Run Club, SEZZ, Vayu Run Club (Kharadi), Dhaav, Veloxx Club and Western Ghats Running are the ones we could confirm.
  • Pune clubs are newer and move fast, so confirm any listed time on the club's own page.

Pune's run clubs are mostly Sunday-morning communities, many of them started in the last couple of years. The clubs below are the ones we could confirm in 2026 from their own pages or a listing.

Looking for the full list? See the Run Clubs in Pune directory (7 clubs, each linked to its source). This post explains how clubs work here; the directory is the page we keep up to date. Each page cites its own sources, so a club can appear in one and not the other.

How run clubs work in Pune

Alpha Run Club's site says it runs every Sunday morning at dawn and sends the coordinates for each session to registered members by Wednesday or Thursday. SEZZ describes a weekly pattern across the week, with a monthly night run on FC Road. Vayu Run Club says it hosts weekly runs, fitness and connection in Kharadi for all fitness levels. A crew directory lists Dhaav on Sundays at 7:00 and Veloxx Club on Mondays at 7:03. So: check the club's page, register if asked, and wait for the exact pin.

Popular places to run in Pune

One city guide (magicpin; it contradicts itself on several figures, so we omit numbers) names Vetal Tekdi in Pashan, Lakaki Lake in Model Colony, the Mula-Mutha riverside and the Pune University campus. It also describes the Sinhagad Fort road climb, saying it is closed to vehicles for runners and cyclists on Sundays. Rules and timings change, so check on the spot. What to bring and what to ask before joining

  • Bring: water, a headlamp or reflective item for dawn, ID, and a phone for the group's WhatsApp or app.
  • Ask: Where is the pin this week? Is there a beginner pace? Is it free? Do I register first?
  • Trail runs: ask about distance and difficulty. If you have any health doubts, talk to a doctor.

Quick questions

When do Pune run clubs meet?

Alpha Run Club says every Sunday morning at dawn, with the coordinates shared by Wednesday or Thursday. SEZZ's site shows a Sunday 6 AM run from Baner Road, though it also lists a Saturday slot, so check.

Which area of Pune has run clubs?

Alpha Run Club lists Viman Nagar, Kalyani Nagar, Koregaon Park, Baner, Kothrud, Magarpatta, Aundh, Kharadi and Pune Station. Vayu Run Club is based in Kharadi.

Is there a trail running option near Pune?

Western Ghats Running lists a training route in the Rajgad to Torna range. Check the club for beginner suitability; ultra training is not for first-timers.

Do I have to register?

Often yes. Alpha Run Club sends the location to registered members. Ask the club how it works.
