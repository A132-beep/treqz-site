Mumbai's run clubs, often called crews, mostly meet early on the seafront or in a city park. The clubs below are the ones we could confirm, with what each source says about when and where they run.

Looking for the full list? See the Run Clubs in Mumbai directory (12 clubs, each linked to its source). This post explains how clubs work here; the directory is the page we keep up to date. Each page cites its own sources, so a club can appear in one and not the other.

How run clubs work in Mumbai

Many Mumbai groups call themselves crews and run to a weekly pattern. A crew directory shows Bombay Running meeting twice a week at 5:45 AM, and The Mumbai Run Club listed for Sundays at 7:00 AM. Others run themed events: On Tour Run Club's free 5K along Marine Drive ended with breakfast, and The RunBay Club's listing mixes steady-pace runs, a hilly 7K and women-only track sessions. Founders Running Club's Mumbai chapter pairs weekly easy runs with coffee and conversation, for people in the startup world.

Popular places to run in Mumbai

The places the clubs above themselves name are: Marine Drive (starting at NCPA, Nariman Point), Shivaji Park, Carter Road in Bandra, Bandra Fort Garden and the Worli Coastal Road promenade. These are public places, so conditions such as crowds and closures vary. Early morning is the usual choice; our heat and monsoon guide explains why.

What to bring and what to ask before joining

  • Bring: water, a cap, shoes you trust, ID and your phone; carry a little cash or UPI for breakfast.
  • Ask: Is there a beginner pace group? Do I need to RSVP? Is it free? Is the route on a promenade or open road?
  • Health: if unsure about your fitness, see a doctor first. A 5K plan helps beginners.

Quick questions

What time do Mumbai run clubs meet?

Early. Bombay Running's runs are at 5:45 AM per a crew directory, and an On Tour Run Club edition in 2025 started at 6:30 AM. Always confirm the current time with the club.

Where are the popular places to run in Mumbai?

Clubs we found use Marine Drive (NCPA, Nariman Point), Shivaji Park, Carter Road and Bandra Fort Garden, among others.

Are Mumbai run clubs free to join?

Some events are free; the On Tour Run Club listing we read was a free 5K. Fees for others are not stated on the pages we opened, so ask.

Can women join women-only runs?

Some clubs run women-only sessions. The RunBay Club's listing shows women-only track and run sessions, for example.
