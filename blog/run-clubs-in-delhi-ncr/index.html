Delhi NCR has run clubs spread across Delhi, Gurugram and Noida, and many welcome beginners. Below are the ones we could confirm from a 2026 guide, a club page or a club directory, with what each source says about where they run.

Looking for the full list? See the Run Clubs in Delhi directory (9 clubs, each linked to its source). This post explains how clubs work here; the directory is the page we keep up to date. Each page cites its own sources, so a club can appear in one and not the other.

How run clubs work in Delhi NCR

A Time Out Delhi guide (dated 2 September 2026) describes the wider scene as running clubs for beginners and marathon hopefuls, alongside cycling and hiking groups. It also shows how varied joining is: one club uses its own app, one asks you to send an Instagram message, one lists an email address. Gurgaon Runners Group describes itself as a volunteer-led community with weekday track intervals, tempo training and weekend long runs. NCRunners, in Noida, says its weekly runs usually end with a social coffee meet.

Popular places to run in NCR

The clubs above name these places themselves or in the guides we read: Nehru Park in Delhi; the Tilpath Valley, Sanjay Van and Asola Bhatti green belt for trail running and hiking; and Meghdootam Park in Noida. We did not verify opening hours or entry rules for them, so check locally. If the air is poor, see running and air quality in India.

What to bring and what to ask before joining

  • Bring: water, a charged phone, shoes you have already run in, and a light layer for early mornings.
  • Ask: Where exactly is the start? Is there a beginner group? Is it free? Is there an app or form to complete first?
  • Listen to your body: if you have a health condition, talk to a doctor before taking up regular running. New runners can follow a 5K plan.

Quick questions

Which part of NCR has run clubs?

All three. The clubs below include groups in Delhi (such as Run with Reeti at Nehru Park), Gurugram (Gurgaon Runners Group) and Noida (NCRunners, Flare Run Club).

Are Delhi run clubs free?

Some are free and some are not, and the pages we opened rarely state fees. Ask the club directly before the first run.

Is it safe to run in Delhi when the air is bad?

Air quality varies a lot by season. Read running and air quality in India and check the day's reading before heading out.

How do I join?

Time Out Delhi lists an app, an email and Instagram DMs as the ways to reach the four clubs it names. Pick the channel the club itself gives.
