How this works

Each name joins a word from one list with a word from another, and sometimes your city. The lists are written for Indian running groups and avoid brand names. Before you settle on a name, check that the Instagram handle is free and that the name is not a trademark.

Quick questions

How do I choose a run club name?

Keep it short, easy to say out loud, and easy to find on Instagram. A city or area in the name helps new runners find you.

Can I use any name the tool makes?

The tool does not check trademarks or whether the handle is taken. Search the name on Instagram and Google first.

How do I start a run club?

Pick one safe route, one weekly time and a group chat, and run it every week for a month before you grow it.
